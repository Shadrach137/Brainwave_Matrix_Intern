# Project 1 — Customer Shopping Data Analysis

## Overview

This project was completed as part of a remote data analytics internship with Brainwave Matrix Solutions in January 2025. It centers on a retail customer shopping dataset and an Excel workbook intended for spreadsheet-based exploration.

## Files

| File | Description |
| --- | --- |
| `customer_shopping_data.csv` | Retail customer shopping transaction dataset |
| `CustomeShoppping_Data_Project_Main.xlsm` | Excel macro-enabled workbook associated with the analysis |

## Intended analysis

Customer transaction data can be used to explore purchasing patterns, product categories, transaction values, and other descriptive trends. The specific spreadsheet calculations, charts, and conclusions from this internship submission cannot currently be verified because the committed `.xlsm` file is only one byte in size and is not a usable workbook.

## Viewing the data

Download `customer_shopping_data.csv` and open it with Excel, LibreOffice Calc, or a CSV-compatible analysis tool. The dataset is the inspectable artifact in this folder.

## Project context

This is an early learning project retained in its original form. The repository documents the dataset and workbook submitted at the time without claiming findings that cannot be checked from the available files.
