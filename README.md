# Brainwave Matrix Solutions — Data Analytics Internship Projects

This repository contains two task-based projects completed during a remote internship with **Brainwave Matrix Solutions** in **January 2025**. They reflect my early experience working with real-world datasets, spreadsheet analysis, Python, natural language processing (NLP), and data visualization.

## Projects

| Project | Focus | Tools / artifacts |
| --- | --- | --- |
| [Project 1 — Customer Shopping Data Analysis](Project_1/) | Exploring retail customer transaction data | CSV dataset, Excel workbook |
| [Project 2 — Smartphone Brand Sentiment Analysis](Project_2/) | Comparing sentiment in YouTube comments about Samsung, Google Pixel, and Apple iPhone | Python, YouTube Data API, Pandas, TextBlob, Power BI |

### Project 1: Customer Shopping Data Analysis

A retail data exploration task using a customer shopping dataset and an Excel workbook. See the [Project 1 README](Project_1/README.md) for the available files and scope. The uploaded workbook is not currently usable, so specific spreadsheet findings cannot be verified from this repository.

### Project 2: Smartphone Brand Sentiment Analysis

A Python-based workflow for collecting comments from selected YouTube videos, preprocessing text, calculating sentiment polarity, and preparing results for comparison and Power BI visualization. The research question was: **Which of the three smartphone brands received the most favorable sentiment in the sampled YouTube comments?**

See the [Project 2 README](Project_2/README.md) for the scripts, workflow, and limitations.

## What I practiced

- Working with structured retail and social-media datasets
- Collecting data through a public API
- Cleaning text and handling timestamps with Python and Pandas
- Applying introductory NLP sentiment analysis with TextBlob
- Preparing analysis outputs for visual reporting

## Notes

These are archived learning projects from an internship, not production-ready applications. The original implementation has been preserved to reflect the work completed at the time. Some files and script paths have limitations documented in the individual project READMEs.

**Security note:** The original Project 2 collection scripts include a hardcoded YouTube API key. Any active key should be revoked or rotated; documentation changes do not remove secrets from repository history.
